# Петропавл — основа проекта

Пользователь одобрил создание нового проекта и использование mosque-360.glb вместо чашки. GIF сохранён как запасной вариант.

Одностраничная презентация мечети: большой заголовок «Петропавл», центральная модель, минимальная навигация и секции об архитектуре и просмотре. Это основа дизайна, не официальный сайт: не придумывать адреса, расписания, историю или контакты. Тексты редакционные и заменяемые.

Палитра: #100904 фон, #ffedd7 текст, #382416 поверхность, #40372e пунктир. Шрифт Segoe UI/system с кириллицей, заголовки 500, основной текст 400. Модель — единственный пространственный акцент. Размеры адаптивные, без обрезки модели.

Стек: HTML/CSS/ES modules, Three.js 0.186.1 через importmap, Node HTTP сервер только на 127.0.0.1, без установки npm зависимостей. Ошибка 3D показывает GIF и понятный статус. GIF можно остановить рисованием кадра в canvas, reduced-motion отключает автоматическое движение.

Клавиатурные кнопки поворота, масштаба, сброса и паузы. Уменьшение движения, видимый фокус, мобильная компоновка. Проверить реальные GLB, HTTP пути/типы, загрузку в браузере и отсутствие переполнения.
