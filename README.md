# Петропавл — архитектура в пространстве

Новый проект с предоставленной моделью mosque-360.glb. Композиция и движение переработаны по oryzo.ai: закреплённая полноэкранная сцена, вид сверху на чертёжном столе, переход в тёмное пространство и смена ракурсов при прокрутке. Оригинальный объект заменён мечетью; исходные GLB/GIF не изменены.

## Запуск

Нужен Node.js 22.15 или новее. Библиотеки уже находятся в проекте, интернет при запуске не требуется.

```powershell
node server.mjs
```

Открыть http://127.0.0.1:4173. Также можно использовать npm start или ./start.ps1. Остановка — Ctrl+C. Открывать через HTTP, не через file://. Если порт занят: `$env:PORT = '4174'`, затем `node server.mjs`. Сервер доступен только на 127.0.0.1.

## Дизайн и анимация

Одна фиксированная WebGL сцена проходит пять ракурсов: сверху, общий вид, боковые детали, верх фасада и общий свободный обзор. Чертёжный стол исчезает в переходе к тёмному фону. Камера плавно догоняет позицию прокрутки; при уменьшенном движении применяется сразу. Тексты раскрываются строками. Движение на скрытой вкладке останавливается.

Свободный поворот, приближение, сброс и автоматическое вращение доступны в разделе «Обзор 360°». В нём кнопка паузы останавливает автоматическое вращение. До него ракурс задаётся прокруткой. В режиме уменьшенного движения автоматическое вращение отключено, ручное управление доступно. Если WebGL/GLB недоступен, показывается локальный GIF; пауза превращает его в статичный кадр.

Первый экран адаптирует рабочую поверхность оригинала под архитектурную модель. Траектория камеры рассчитана под размеры мечети, а не заимствована у подставки. Исходные фотографии, модель и программный код ORYZO не используются в продукте.

## Где менять

- index.html — секции и подписи, навигация, importmap.
- src/content.js — основные русские тексты и пути к модели/GIF. Настоящие тексты пользователя ещё не предоставлены; текущие — редакционная основа без дат, адресов и расписаний.
- src/styles.css — цвета, сетка, адаптивность и появление текста.
- src/main.js — прокрутка, меню, доступность и запасной режим.
- src/journey.js — пять позиций камеры и плавная интерполяция.
- src/scene.js — GLTFLoader, камера, освещение, стол и управление.
- vendor/three — Three.js 0.186.1 и addons с лицензией MIT.

Контракт сцены: `mountScene({container, modelUrl, onReady, onError, reducedMotion})` возвращает `setProgress(0..1)`, `setInteractive(bool)`, `setRotating(bool)`, `reset()`, `zoom(factor)`, `rotate(radians)` и `dispose()`. При переносе в другую систему освобождать сцену через dispose.

## Проверка

`npm test` — сервер и траектория камеры. `npm run check` — синтаксис и разбор исходного GLB локальным Three.js. Для проверки браузером нужен Python с playwright, Pillow и установленный Chrome: `python scripts/browser-check.py`.

Снимки desktop/mobile и результаты браузерной проверки сохраняются в docs/verification. Референс исследован отдельно в docs/research. Эти папки локальный сервер не публикует.

Для статического хостинга перенести index.html, favicon.svg, src/, vendor/ и обе модели. Сервер, тесты, scripts/ и docs/ для публикации не нужны. Проект пока не опубликован.

Проверены уменьшенное движение, GIF fallback при отказе загрузки GLB и прямой вход #explore до завершения загрузки. Фотографии ORYZO используются только как исследовательские скриншоты.
